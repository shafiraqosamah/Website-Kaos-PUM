## Persyaratan Sistem

PHP Version: Min. PHP 8.2 ke atas
XAMPP: versi PHP 8.2.x atau 8.3.x/8.4.x.
Composer: menginstal dependensi PHP (seperti Laravel dan SDK Midtrans).
Laravel Framework: Versi 12.x
Midtrans PHP SDK: Versi 2.6
Node.js & NPM
Database: MySQL atau MariaDB
