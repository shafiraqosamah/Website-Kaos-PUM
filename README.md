## Persyaratan Sistem

<li> PHP Version: Min. PHP 8.2 ke atas </li>
<li>XAMPP: versi PHP 8.2.x atau 8.3.x/8.4.x.</li>
<li>Composer: menginstal dependensi PHP (seperti Laravel dan SDK Midtrans).</li>
<li>Laravel Framework: Versi 12.x</li>
<li>Midtrans PHP SDK: Versi 2.6</li>
<li>Node.js & NPM</li>
<li>Database: MySQL atau MariaDB</li>
